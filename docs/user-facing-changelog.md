# Jack House V3 更新日志

本文面向 Jack House 用户，说明 `jack-house-v3` 相比旧版 `jack-house-web/frontend` 的主要更新。

## 总览

Jack House V3 是一次全站前端升级。新版保留了论坛、图包、活动、用户资料、赛事和后台管理等核心功能，同时重做了页面体验、登录安全、富文本编辑、赛事系统和后台工具台。

## 主要更新

### 全站体验升级

- 页面视觉和交互全面重做，导航、按钮、表单、弹窗、分页、空状态和错误提示更加统一。
- 首页保留 JACK HOUSE、JACKMAPS、TOURNEY 三个核心入口，并改为全屏沉浸式视觉展示。
- 新增更完整的浅色 / 深色主题体验，首页会自动使用深色视觉。
- 移动端导航和页面布局重新适配，手机访问时操作更清晰。
- 中英文内容体系重新整理，论坛、图包、活动、赛事和后台文案更统一。

### 登录与账号更安全

- 登录态升级为更安全的 Cookie 会话，不再依赖旧版浏览器本地 token。
- 支持账号密码登录和 osu! 登录。
- 需要登录的操作会自动弹出登录窗口，并在登录后回到原操作页面。
- 个人资料编辑聚焦常用信息：密码、QQ、Discord。

### 论坛与文章体验升级

- 论坛列表支持搜索、类型筛选和分页。
- 发帖编辑器升级，支持普通帖、征稿帖、活动帖等不同类型。
- 编辑器支持中英文内容分别编辑，并提供本地草稿保存。
- 富文本能力增强：支持标题、列表、引用、代码块、链接、图片上传、粘贴图片、拖拽图片和表格。
- 帖子详情页新增文章目录，长文阅读更方便。
- 作者或管理员可以直接在帖子详情页编辑、删除帖子。
- 征稿帖的投稿面板重新整合，投稿状态、限制和错误提示更明确。
- 评论区体验统一，帖子和图包评论使用一致的展示与分页方式。

### 图包体验升级

- 图包列表重新设计，支持关键词搜索、类型筛选、状态筛选、标签筛选、排序和分页。
- 图包卡片展示更清晰，下载入口支持 osu!、osu.direct、Sayobot 等外部链接。
- 图包详情页重做，谱面展示、图包信息、下载链接、描述和评论更集中。
- 新建图包流程保留 osu! 导入和手动外链创建能力，表单提示和校验更完整。
- 管理员维护图包的入口整合到详情页，减少来回跳转。

### 活动页面升级

- 活动详情页重做，活动封面、阶段、规则、个人分数和排行榜展示更直观。
- 排行榜支持分页和高亮展示，活动期间查看成绩更方便。
- 成绩同步、提交和倒计时状态提示更明确。
- 活动内容统一使用新版富文本渲染，图片、表格和长文排版更稳定。

### 赛事系统大幅升级

- 新增完整赛事入口 `/t`，赛事列表会展示赛事封面、名称、缩写和当前状态。
- 赛事详情页升级为赛事主页，集中展示封面、简介、Staff、规则、说明、奖项、FAQ 等内容。
- 赛事规则和说明支持中英文内容，并带有目录导航。
- 报名和组队体验升级：
  - 支持创建队伍、加入公开队伍、使用邀请码加入私密队伍。
  - 队长可以编辑队伍信息、提交队伍、重置邀请码、转让队长、移除成员。
  - 队员可以退出队伍。
  - 报名窗口关闭、已加入队伍、Staff 禁止报名等状态会有明确提示。
- 资格赛页面升级：
  - 展示资格赛图池。
  - 支持总排名和单图排名切换。
  - 展示队伍、选手、排名和分数。
- 正赛页面升级：
  - 支持正赛对阵表展示。
  - 支持比赛详情页，展示双方队伍、比分、图池、已进行对局和比赛状态。
- 裁判工作台升级：
  - 支持记录 Roll 点。
  - 支持记录 Protect、Ban、Pick。
  - 支持记录暂停。
  - 支持修正单局比分。
  - 支持查看操作时间线和下一步操作提示。

### 后台管理升级

- 后台整体改为更适合管理工作的工具台布局，表格、筛选、分页和操作按钮更统一。
- 仪表盘升级为数据看板，新增近 30 天 PV、UV、登录用户、活跃时长、用户增长和热门页面图表。
- 用户、帖子、公告、投稿文件、徽章、活动、活动阶段等后台页面完成新版迁移。
- 权限控制更细：不同后台页面按权限展示，未授权用户不会进入对应管理页。

### 赛事后台新增能力

- 新增赛事列表和赛事创建页。
- 新增赛事设置页，可维护赛事基础信息、时间、队伍人数、资格赛晋级名额等配置。
- 新增赛事内容管理页，可维护规则、说明、奖项、FAQ 等章节，并支持 Markdown 预览。
- 新增赛事队伍管理页，可审核队伍、批量通过、维护选手信息。
- 新增赛事 Staff 管理页，可维护赛事工作人员。
- 新增历史数据导入页，支持 Google Form / CSV 和高级 JSON 导入，并提供 dry-run 预检查。
- 新增资格赛管理页：
  - 管理资格赛图池。
  - 从 MP 导入成绩。
  - 支持批量导入多个 MP。
  - 支持手动修正成绩。
  - 支持重新计算排名。
  - 支持锁定资格赛排名。
  - 展示导入记录和原始成绩数量。
- 新增正赛管理页：
  - 管理轮次。
  - 管理轮次图池。
  - 生成对阵。
  - 创建和维护比赛。
  - 拉取比赛分数。
- 新增赛事审计日志，可查看队伍、选手、Staff、内容、资格赛、正赛和裁判操作的修改记录。

### 内容和上传能力增强

- 富文本图片上传接入新版存储流程，支持工具栏上传、粘贴上传和拖拽上传。
- 富文本表格支持插入、追加行列和删除。
- 投稿文件、富文本图片、活动图片、徽章等公开图片展示流程更统一。
- 投稿上传增加文件大小、扩展名、校验和等限制，上传更稳定。

## 变化说明

- V3 继续复用旧后端和旧数据，用户的账号、帖子、图包、活动和赛事数据不会因为前端升级而重建。
- 旧版首页图管理不再作为新版首页展示来源，新版首页使用固定视觉素材。
- 旧版赛事中的部分独立入口在新版中被整合：
  - 报名入口整合进组队大厅。
  - 规则入口整合进赛事主页内容章节。
  - 排名入口整合进资格赛和正赛相关页面。
- 邮箱注册界面暂未作为 V3 用户功能开放，新用户主要通过 osu! 登录/注册流程进入。

## 推荐用户关注

- 普通用户：登录、浏览论坛、发帖、投稿、搜索图包、参与活动和赛事报名的体验都有明显变化。
- 赛事选手：重点关注新的赛事主页、组队大厅、资格赛排名、正赛对阵和比赛详情。
- 裁判与 Staff：重点关注裁判工作台、赛事后台、资格赛导入、排名锁定和审计日志。
- 管理员：重点关注新版后台权限、数据看板、赛事管理和富文本内容管理。
